# Материалы преподавателя

Источник: https://github.com/AnatoDu/Introduction_to_AI — Дуркин Анатолий Альбертович, старший преподаватель.
Версия содержимого и точные SHA-256 файлов — manifest.json. Этот код поставлен с курсом и не является самостоятельной работой студента. Сохраняйте указание источника при размещении своего проекта. Общая лицензия исходного репозитория не задана; открытая лицензия этим файлом не объявляется.

checks.py даёт подсказки, не выставляет оценку и не доказывает самостоятельность. Учебные CSV: ai_systems — набор примеров AI-систем для обсуждения; gost_59277_classes — справочная учебная таблица классификации по ГОСТ Р 59277-2020, не замена официальному тексту стандарта. Это учебные материалы, а не данные вашего собственного проекта.

Для запуска уже полученных занятий соседний репозиторий преподавателя не нужен. Собственный исследовательский код в notebooks/ не должен импортировать учебные проверки. Обновление — по docs/GIT.md, без замены своих ответов. Не редактируйте checks для получения зелёной галочки; сомнительную проверку обсудите с преподавателем.

В репозитории курса эта папка — источник. В личном проекте — поставленный снимок. Импорты одинаковые: `from course_support.checks import check`; путь к учебным данным — `from course_support import DATA_DIR`.
