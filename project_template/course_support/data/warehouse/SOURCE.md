# Учебные данные аналитики и хранилища

Все записи синтетические, созданы для курса. Разрешено использовать и изменять с указанием курса.
Реальных клиентов, магазинов и финансовых сведений нет. Источник: demo.json (UTF-8).
daily: одна строка — показатель магазина за условный день эксперимента; day — номер дня,
revenue — известная сумма в условных денежных единицах. Пропущенный день означает отсутствие записи,
а не нулевую сумму. Пара (store,day) уникальна. Это отдельный набор для оконных функций.
customers: уникальный customer_id и условный город. events: исходная выгрузка событий;
event_id — ключ события, customer_id — ссылка на справочник, amount — стоимость.
Ноль — допустимая акция, null — стоимость пока неизвестна. Отрицательные стоимости не допускаются
правилами именно этого учебного источника. s02 повторён точно; s03 отрицателен; клиент Z отсутствует.
При приёме выгрузки эти строки сохраняют для расследования, а не стирают из исходника.
