# Palmer Penguins — локальный учебный снимок

Реальные измерения Kristen Gorman и Palmer Station LTER; пакет Allison Horst, Alison Hill, Kristen Gorman.
344 строки, 8 полей, три вида, наблюдения 2007–2009. CSV сохранён без изменения содержимого.
Это упрощённый опубликованный набор, а не все исходные полевые записи. Пропуски NA сохраняются.
Масса в граммах, размеры клюва и ласта в миллиметрах. Номер строки не является постоянным ID птицы.
