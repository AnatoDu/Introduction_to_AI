# Учебный каталог

Синтетический набор курса, создан программно для блока 3. Не является выгрузкой реального сайта или рынком Сыктывкара. Адреса, названия и цены вымышлены, персональных данных нет. Разрешено использовать, изменять и распространять в учебных проектах с указанием источника — курс А. А. Дуркина.

Три локальные HTML-страницы, 12 карточек, 10 уникальных ID. Повторы на стыке страниц и две цены «По запросу» добавлены намеренно. Одна строка результата — объявление; ID — ключ внутри этого каталога. Цена — рубли, площадь — м²; пропуск цены не означает нулевую цену. `robots.txt` — учебный пример, URL в упражнении не запрашивается.

Откройте page-1.html обычным браузером. Интернет и HTTP-сервер не нужны. Источник обновлений: каноническая course_support/data/parsing курса Introduction_to_AI.
