# Учебный журнал прослушиваний

Полностью синтетические данные, созданные для этого курса. Людей, реальных городов,
записей музыкального сервиса и настоящих музыкальных произведений здесь нет.
Разрешено использовать и изменять в учебных работах с указанием курса как источника.

`listens.csv`: одна строка — одно событие прослушивания. `event_id` — уникальный текстовый
ключ события; `track_id` — ссылка на трек (может повторяться); `city` — условная площадка
«Север»/«Юг»; `minutes` — известное число прослушанных минут. Пустота означает неизвестную
длительность; 0 — известное нулевое время, а не пропуск. 12 событий, 10 известных длительностей.

`tracks.csv`: одна строка — один трек; `track_id` уникален; `title` и `genre` — вымышленные
название и жанр. t99 отсутствует в справочнике намеренно. t05 есть в справочнике, но не слушался.
Пустых ключей нет. Это маленький учебный пример для группировок, соединений и SQL,
не основание для выводов о музыкальных предпочтениях населения. CSV: UTF-8, запятая.
