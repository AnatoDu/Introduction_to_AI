# Работа с материалами

GitHub и Git необязательны весь семестр. Работайте в локальных тетрадях и сохраняйте отдельную копию. Сдача файлами или архивом равноправна ссылке на репозиторий; критерии и баллы одинаковы. Публиковать проект на GitHub можно по желанию, в том числе дома через браузер.

## Первый запуск

Скачайте курс через Code → Download ZIP на GitHub или получите комплект у преподавателя. Скопируйте `project_template` целиком в личную папку; готовый архив проекта просто распакуйте. Откройте нужный `.ipynb` в `workbooks`. Рядом должна быть `course_support` с учебными данными и проверками. Не работайте внутри ZIP. Название и расположение личной папки выбираете сами.

Если Jupyter не работает, сообщите преподавателю; для первого блока есть `00. Старт без установки.ipynb` и `СТАРТ_БЕЗ_УСТАНОВКИ.html`. Для дальнейших блоков используйте резерв конкретного занятия. Не тратьте пару на регистрацию и установку Git.

## Как добавить новое занятие

1. Сохраните ответы и сделайте резервную копию всей своей папки.
2. Получите новую выдачу в отдельную папку.
3. Из `workbooks` перенесите только новые тетради. Если файл уже есть — не заменяйте свою работу; сохраните исправленный вариант под другим именем.
4. Обновите `course_support` целиком и справочные `docs`. Собственные данные храните в `data`, не в `course_support/data`.
5. Свои README, notebooks, data и reports не заменяйте. Перезапустите kernel и проверьте новый notebook. Старую копию сохраните до проверки.

## Сохранение

В конце пары сохраните тетради и копию всей своей папки на другом доступном носителе или в хранилище. Откройте копию и проверьте последний ответ. Сдача — [СДАЧА.md](СДАЧА.md). Для добровольной публикации — [GIT.md](GIT.md).
