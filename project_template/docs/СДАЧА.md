# Как сдавать

Общий сервис курса — **GitHub**. На первом блоке принимаются обычные файлы; аккаунт и репозиторий нужны к следующему занятию. Начните с [ПЕРВЫЙ_СТАРТ.md](ПЕРВЫЙ_СТАРТ.md).

## Сегодня

Сохраните тетрадь и README. Сделайте копию всей папки проекта в другом доступном месте: на личном носителе, другом устройстве или в подходящем хранилище. Откройте копию и проверьте последний ответ. Если перенос пока недоступен, согласуйте с преподавателем способ сохранения результата. Git-коммит сам по себе не создаёт копию на другом устройстве.

## Со следующей недели

- Один репозиторий этого курса: README, свои notebooks в workbooks, необходимые разрешённые данные и код.
- Публичный или приватный с доступом преподавателю. Передайте ссылку и отметьте, какая работа готова к проверке. Таблица оценок не заменяет саму сдачу; баллы выставляет преподаватель.
- Если Git не настроен, первый результат можно загрузить через сайт GitHub. Дальше освоим commit/push. История локального Git через Upload files не переносится.
- Если регистрация/доступ объективно не работают, временно сдайте файл и сообщите конкретное препятствие. Работа продолжается; другой сервис не становится основной заменой GitHub автоматически.

## Что проверяем

Ноутбук с вашими ответами, воспроизводимый учебный результат, объяснение и необходимые данные. На первом блоке резервная тетрадь/письменный результат принимаются наравне с основным маршрутом. Не загружайте `_teacher`, `.git`, окружения, пароли, токены, чужие работы и непроверенные персональные данные. Сырые большие фото/видео храните отдельно.

Баллы и сроки лабораторных — в [ОЦЕНИВАНИЕ.md](ОЦЕНИВАНИЕ.md); новые штрафы этим уточнением не вводятся. Правила Git — в [GIT.md](GIT.md).

## Что остаётся неизменным

Номер тетради NN.M — блок и пара, номер ЛР — оцениваемая работа: это разные номера. Первые 01.1/01.2 — тренировочный старт, не сдача полной ЛР1. Её условия и срок будут объявлены отдельно. Минимум первого дня и резерв принимаются без отдельных баллов за активность.

Приоритет правил: ОЦЕНИВАНИЕ.md — баллы; ПРОЕКТ.md — границы проекта; СДАЧА.md — передача результата. Рабочие тетради уточняют упражнения. Поздние исправления не вводят задним числом новые требования; существенные изменения объявляются группе с пояснением. Уже заполненные тетради не заменяем.
