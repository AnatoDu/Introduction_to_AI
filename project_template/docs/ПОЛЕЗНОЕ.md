## Как пользоваться списком

Один материал по желанию после блока, не список обязательных долгов. На занятии — 5–7 минут и конкретный вопрос. Конкурсы/регистрации ниже проверяем перед объявлением; наличие старой ссылки не означает открытый набор. Победа в соревновании не требуется для зачёта.

Для первого блока: [Moneyball / «Человек, который изменил всё»](https://www.sonypictures.com/movies/moneyball) — повод спросить, что измеряли и почему привычная оценка могла ошибаться; художественный фильм, не учебник и не точная хроника. Для желающих готовиться к следующему блоку — раздел о Jupyter или начале pandas в [книге Уэса Маккинни](https://wesmckinney.com/book/), а не вся книга. Онлайн-издание ориентировано на pandas 2, отдельные детали сверять с установленной версией.

# Полезное и интересное

Необязательное, но полезное: тренажёры, книги, фильмы и соревнования по темам курса. Список пополняется по ходу семестра — если нашли что-то стоящее, пишите, добавим.

## По занятиям

### Занятие 1. Курс, рабочее место, задача ИИ

- Тренажёр: [Learn Git Branching](https://learngitbranching.js.org/?locale=ru_RU) — Git в картинках и задачах, есть русский язык.
- Книга: [Pro Git](https://git-scm.com/book/ru/v2) — всё про Git, бесплатно и по-русски. Для начала хватит первых трёх глав.
- Совет: [как задать вопрос, чтобы вам помогли](https://ru.stackoverflow.com/help/minimal-reproducible-example) — минимальный воспроизводимый пример. Пригодится и на паре, и на работе.
- Фильм: «Человек, который изменил всё» (Moneyball, 2011) — менеджер бейсбольной команды без денег собирает сильный состав с помощью статистики. По сути, фильм про наш курс.
- Фильм: «Игра в имитацию» (2014) — об Алане Тьюринге, с которого начинается разговор о «думающих машинах».
- Книга: Ханна Фрай «Hello World. Как быть человеком в эпоху машин» — лёгкая книга о том, где алгоритмы уже решают за людей: в медицине, суде, транспорте.

### Занятие 2. Pandas

- Книга: Уэс Маккинни [«Python for Data Analysis»](https://wesmckinney.com/book/) — книга создателя pandas, третье издание бесплатно на сайте автора. На русском выходила как «Python и анализ данных».
- Введение: [10 minutes to pandas](https://pandas.pydata.org/docs/user_guide/10min.html) — официальный короткий обзор.
- Тренажёр: [Kaggle Learn: Pandas](https://www.kaggle.com/learn/pandas) — мини-курс с задачами и автопроверкой.

### Занятие 3. Парсинг

- Песочница: [books.toscrape.com](https://books.toscrape.com/) — сайт, созданный специально для тренировки парсинга.
- Документация: [Beautiful Soup на русском](https://www.crummy.com/software/BeautifulSoup/bs4/doc.ru/).

### Занятие 4. API и открытые данные

- Каталог: [Public APIs](https://github.com/public-apis/public-apis) — сотни открытых API на любую тему.
- Данные: [Our World in Data](https://ourworldindata.org/) — открытые данные по всему миру с отличными графиками.
- Источники наших треков: [OpenAlex](https://api.openalex.org/works?per-page=1) (наука), [ЦБ РФ](https://www.cbr.ru/development/SXML/) (курсы валют), [Epoch AI](https://epoch.ai/data/ai-models) (модели ИИ).

### Занятие 5. Предобработка

- Статья: Хэдли Уикхем [«Tidy Data»](https://www.jstatsoft.org/article/view/v059i10) — классика о том, как должна выглядеть аккуратная таблица (на английском).

### Занятия 6–7. SQL

- Игра: [SQL Murder Mystery](https://mystery.knightlab.com/) — детектив, в котором убийцу ищут SQL-запросами.
- Тренажёр: [SQL Academy](https://sql-academy.org/ru) — задачи по SQL на русском.
- Учебник: [Select Star SQL](https://selectstarsql.com/) — интерактивный, на английском.

### Занятие 8. Визуализация

- Навигатор: [From Data to Viz](https://www.data-to-viz.com/) — какой график выбрать под ваши данные.
- Для смеха: [Spurious Correlations](https://www.tylervigen.com/spurious-correlations) — ложные корреляции: потребление сыра и смерти от запутывания в простынях.
- Книги: Дарелл Хафф «Как лгать при помощи статистики», Чарльз Уилан «Голая статистика», Коул Нафлик «Сторителлинг на языке данных».

### Занятие 9. Тренды ИИ

- Данные: [Epoch AI](https://epoch.ai/data/ai-models) — база моделей ИИ, с которой мы работаем.
- Обзоры: [State of AI Report](https://www.stateof.ai/) и [Stanford AI Index](https://hai.stanford.edu/ai-index) — главные ежегодные отчёты об ИИ.

### Занятие 10. Разметка

- Попробовать: [Label Studio Playground](https://labelstud.io/playground/) — разметка прямо в браузере.

### Занятие 11. Персональные данные

- Проверить себя: [Have I Been Pwned](https://haveibeenpwned.com/) — не утекала ли ваша почта. Результат смотрите сами, никому его показывать не нужно.
- Закон: [152-ФЗ «О персональных данных»](https://www.consultant.ru/document/cons_doc_LAW_61801/).
- Фильм: «The Great Hack» (2019) — документальный фильм о скандале с Cambridge Analytica.

### Занятие 12. Этика

- Попробовать: [Moral Machine](https://www.moralmachine.net/) — решите «проблему вагонетки» за беспилотный автомобиль.
- База: [AI Incident Database](https://incidentdatabase.ai/) — реальные случаи, когда ИИ ошибался или навредил.
- Документ: [Кодекс этики в сфере ИИ](https://ethics.a-ai.ru/).
- Фильм: «Coded Bias» (2020) — документальный фильм о том, как системы распознавания лиц ошибаются на одних людях чаще, чем на других.
- Книга: Кэти О'Нил «Убийственные большие данные».
