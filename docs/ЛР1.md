# ЛР1. Основы pandas — 15 баллов

Работа на предоставленном titanic.csv; тема собственного проекта для неё не нужна. Создайте notebooks/lab01.ipynb, прочитайте ../course_support/data/titanic.csv (при запуске из notebooks). Если Jupyter запущен из корня, используйте course_support/data/titanic.csv. Не используйте абсолютный путь своего компьютера; напишите, откуда запускать тетрадь.

1. **Выборка и сортировка — 4 балла.** Выберите пассажиров не моложе 18 лет третьего класса; оставьте Name, Age, Fare. Покажите пять самых дорогих билетов этой группы. Покажите отдельный пример loc и iloc и объясните различие.
2. **Агрегации — 4 балла.** Посчитайте количество пассажиров и долю выживших по классу. Сравните средний и медианный возраст по полу. Подпишите показатели; напишите два вывода, подтверждённых числами.
3. **Диагностика — 3 балла.** Размер, типы, пропуски по столбцам. Объясните, что происходит с пропусками при подсчёте среднего возраста. Покажите число дубликатов и объясните, почему равенство отдельных признаков не делает людей дубликатами. Не удаляйте данные без обоснования.
4. **Воспроизводимость и объяснения — 4 балла.** Restart Kernel → Run All без ошибок, осмысленные подписи, одно ограничение выводов, приложенный CSV или сохранённая структура комплекта. Работа должна запускаться без checks.py и без преподавательского репозитория.

Срок преподаватель объявляет при выдаче. [Полные критерии](ОЦЕНИВАНИЕ.md), [сдача файлами или ссылкой](СДАЧА.md). Дополнительные исследования добровольны, отдельного бонуса нет. Код объясните своими словами; помощь ИИ раскройте.
