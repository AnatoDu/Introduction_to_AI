Введение в ИИ: старт без установки

Запасная тетрадь для первого блока. Нужен только Python 3; интернет, Git, pandas и checks не нужны. Если не запускается даже kernel, откройте HTML-версию и запишите ответы в текстовый файл или на бумаге. Это тот же учебный минимум, а не штрафной вариант.

Сначала сохраните собственную копию. В конце каждого задания: что ожидали → что получили → почему. Сегодня нет задачи поставить всё программное обеспечение мира.

1. Знакомство и первая программа — 25 минут

Коротко запишите: что уже делали на Python; что можете сделать без подсказки; что пока непонятно. Можно ответить «не пробовал».

Предскажите результат кода, запустите. Измените число недель на 10. Как изменится ответ? Затем самостоятельно вычислите число академических часов, если одна пара — два часа.

weeks = 12
pairs_per_week = 2
pairs_total = weeks * pairs_per_week
print("Пар:", pairs_total)

2. Задача раньше технологии — 30 минут

Пример: библиотеке нужно предсказывать спрос на книги на следующую неделю. Вход — история выдач до сегодняшнего дня; выход — оценка числа выдач; решение — сколько экземпляров подготовить.

Выберите свою систему: рекомендация музыки, фильтр спама или поиск расписания. Запишите вход, выход, кто использует результат и цену ошибки. Может ли часть задачи решаться обычными правилами? Почему название «нейросеть» ещё не является постановкой задачи?

Сначала каждый пишет 3–4 строки, затем сравнивает с соседом.

5. Правило или обучение? — 25 минут

Для фильтра сообщений можно написать правило: если есть слово «приз», помечать как спам. Запустите baseline. Укажите ложное срабатывание и пропуск; придумайте ещё одно сообщение, на котором правило ошибётся.

Не подгоняйте ответ под каждый пример отдельным if: объясните, какие данные понадобились бы для обучения и проверки модели.

messages = ["Получите приз прямо сейчас", "Ты получил приз на олимпиаде?", "Вы выиграли миллион", "Пара в аудитории 204"]
def is_spam(text):
    return "приз" in text.lower()
for text in messages:

6. Черновик своего проекта — 30 минут

Заполните карточку: вопрос; кому полезен ответ; что означает строка данных; 3–5 полей; предполагаемый источник; что нужно проверить в условиях использования; что будет результатом через неделю.

Пример масштаба: сравнить расписание и фактическое время поездки на одном маршруте. Не собирать персональные данные пассажиров. Не «создать искусственный интеллект для транспорта».

Обменяйтесь карточками: сосед задаёт один вопрос о данных. Преподаватель помогает уточнить слишком широкие темы.
