# Домашняя среда: из своей папки проекта

На первом занятии ничего устанавливать не обязательно: можно использовать уже работающую среду. Рабочий резерв — в [ПЕРВЫЙ_СТАРТ.md](ПЕРВЫЙ_СТАРТ.md). Дома настройте среду по возможности; если компьютера дома нет, сообщите преподавателю — договоримся о доступном рабочем месте.

1. Установите Python 3.12 с [python.org](https://www.python.org/downloads/). Если подходящий Python уже есть, менять его перед первой парой не нужно. На Windows при установке включите добавление Python в PATH.
2. Перенесите **всю свою папку проекта**, с ответами, workbooks и course_support. Не скачивайте новый шаблон поверх работы. Если проект уже на GitHub — скачайте свой репозиторий. Копия курса рядом не нужна.
3. Откройте терминал **в корне своего проекта**, там, где README.md и requirements.txt. Создайте отдельное окружение и запускайте команды для своей системы.

Windows, PowerShell (активация не требуется):

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m jupyterlab
```

macOS / Linux:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m jupyterlab
```

В открывшемся Jupyter перейдите в workbooks. После завершения работы сохраните тетрадь. Окружение .venv не публикуйте и не переносите между компьютерами: на другом устройстве создайте его заново. Исходники и данные переносим, установленный Python — нет. [Документация Python о venv](https://docs.python.org/3/library/venv.html).

## Если не получилось

Не устанавливайте пакеты в случайный системный Python. Сохраните текст ошибки и сообщите преподавателю. На занятии используйте резерв; недоступный сервер пакетов не означает потерю учебного результата. requirements.txt содержит набор курса с нижними границами версий, а не гарантию всех будущих сочетаний; точные версии собственного проекта зафиксируем по мере работы.

## GitHub и Git

К следующему занятию нужен GitHub с вашим результатом. Можно начать через сайт. Для локального Git — [официальные установщики](https://git-scm.com/downloads) и [наша шпаргалка](GIT.md). Вход на общем компьютере не настраиваем ради первого занятия.
