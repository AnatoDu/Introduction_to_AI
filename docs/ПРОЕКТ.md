# Семестровый проект

За семестр каждый из вас пройдёт весь путь работы с данными на своей теме: найдёт источник, соберёт данные, почистит их, сложит в хранилище, проанализирует, покажет на дашборде и проверит на законность. В итоге получится самостоятельная папка проекта; по желанию её можно опубликовать на GitHub и показать в резюме. В ML можно продолжить подходящий проект: сначала проверим, есть ли корректная задача, целевая переменная и достаточные данные. При необходимости выберем другой набор.

На первом занятии достаточно самостоятельной папки проекта и проверенной копии. GitHub можно подключить по желанию. См. [СДАЧА.md](СДАЧА.md).

Проект **индивидуальный**. Лабораторные 2–6 — его этапы.

## Треки

Можно выбрать тему из меню или предложить свою. Сегодня — предварительная идея и один вопрос; до следующего блока — неделя на размышление. Приносите карточку: вопрос, источник и небольшой пример доступных данных, предполагаемый результат, трудности. После проверки посильности и условий использования согласуем тему. Источники ниже — кандидаты, их актуальный доступ не гарантируется.

| Трек | Источник данных | Что собираем | Примеры вопросов | Варианты |
|---|---|---|---|---|
| Рынок труда Коми | открытый API портала «Работа России» | вакансии: профессия, зарплата «от–до», город, график, требования к опыту и образованию, работодатель | Где платят больше? Какая доля вакансий доступна без опыта? | группа профессий: IT, медицина, образование, строительство; сравнение с соседним регионом |
| Недвижимость Сыктывкара | учебный сайт объявлений (парсинг) | объявления: цена, площадь, комнаты, этаж, район, материал дома, текст объявления | Сколько стоит квадратный метр в разных районах? Что сильнее всего влияет на цену? | квартиры, дома, аренда |
| Наука региона | API OpenAlex | научные статьи: год, темы, авторы, цитирования, соавторства | Как меняется число публикаций? Кто с кем пишет статьи? | СГУ и ещё один вуз на выбор |
| Климат Коми | API Open-Meteo | ежедневная погода за десятки лет | Теплеет ли в Сыктывкаре? Сколько стало экстремальных дней? | набор городов и период |

Свой источник тоже возможен — после проверки законности и согласования с преподавателем.

## Этапы

| Когда | Этап | Что появляется в проекте |
|---|---|---|
| Занятие 1 | Старт | самостоятельная папка из шаблона, предварительная тема, один вопрос; три вопроса — расширение |
| Занятия 3–4 | ЛР2: сбор данных | скрипт сбора, сырые данные, паспорт датасета, проверка законности |
| Занятия 5–6 | ЛР3: очистка | очищенные данные, список найденных проблем, проверки качества |
| Занятия 6–8 | ЛР4: хранилище и анализ | база DuckDB со слоями, SQL-запросы, ответы на вопросы с графиками, дашборд |
| Занятия 9–10 | ЛР5: разметка и документация | общая разметка, паспорт датасета, оценка стоимости данных |
| Занятия 11–12 | ЛР6: аудит и защита | проверка персональных данных и перекосов, README для портфолио, короткая демонстрация результата и проверка собственного решения |

Что проверяется на каждом этапе — в [ОЦЕНИВАНИЕ.md](ОЦЕНИВАНИЕ.md), отмечать выполненное удобно в `CHECKLIST.md` вашего проекта.

## Каким должен получиться проект

- README, из которого за минуту понятно: какая задача, какие данные, что получилось и как это запустить.
- Код, который запускается с нуля на другом компьютере.
- Сырые и очищенные данные (или скрипт, который их скачивает, если данных много).
- Паспорт датасета.
- Пример дашборда/интерактивного отчёта и инструкция локального запуска. Платный сервис и публичный хостинг не требуются.
- Краткое описание на английском — добровольное дополнение для портфолио, без отдельных баллов.

## Советы для портфолио

- Поместите задачу, главный результат и пример в начало README: читатель должен быстро понять вашу работу.
- Пишите выводы цифрами: не «в Сыктывкаре платят больше», а «медианная зарплата в Сыктывкаре на 18% выше, чем в Ухте».
- Коммитьте часто и с понятными сообщениями — история коммитов тоже рассказывает о вас.
- Никаких ключей API, паролей и персональных данных в репозитории.
- В резюме проект описывается одной строкой: что сделали, на каких данных и с каким результатом.
