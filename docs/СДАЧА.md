# Как сдавать

GitHub и Git необязательны весь семестр. Работайте в локальных тетрадях и сохраняйте отдельную копию. Сдача файлами или архивом равноправна ссылке на репозиторий; критерии и баллы одинаковы. Публиковать проект на GitHub можно по желанию, в том числе дома через браузер.

## Файлами

Сохраните выполненный `.ipynb`. Если ему нужны данные и `course_support`, отправьте ZIP всей своей рабочей папки с этими файлами. Не включайте `.git`, окружения, кеши, пароли, чужие работы. Проверьте распаковку в новую папку и запуск тетради. Если данные нельзя пересылать, приложите разрешённый пример и инструкцию получения.

## Через GitHub — по желанию

Отправьте ссылку на публичный репозиторий или предоставьте преподавателю доступ к приватному. Укажите файл и готовую работу. Загрузка через сайт описана в [GIT.md](GIT.md); Git на компьютере аудитории не требуется. Сам push не уведомляет преподавателя о сдаче.
