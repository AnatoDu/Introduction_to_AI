# Один набор в разных форматах

Три вымышленные станции, специально созданные для курса А. А. Дуркина. Это не показания погоды и не наблюдения реальных станций. Учебное использование разрешено с указанием источника. Строка — одна станция в одном учебном наблюдении; период реальных измерений отсутствует. station_id — строковый идентификатор с ведущими нулями; city — подпись; temperature_c — условная температура в градусах Цельсия. CSV: Windows-1251, разделитель ;, десятичная запятая. XML: UTF-8, числа с точкой. Данные отражают одну и ту же таблицу; различается способ записи. Пропусков нет, искусственно искать их не требуется.
