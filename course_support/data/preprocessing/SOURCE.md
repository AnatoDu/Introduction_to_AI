# Учебные заявки на короткие курсы

Полностью вымышленный набор для практики А. А. Дуркина. Не анкета студентов,
не сведения реального учебного центра и не оценка рынка образовательных услуг.
Разрешено использовать, изменять и распространять для учёбы и в учебных проектах
с указанием этого происхождения. Персональных данных реальных людей нет.

Одна строка сырого файла — запись выгрузки о заявке, а не гарантированно новая
заявка. Request ID должен идентифицировать одну заявку; ведущие нули значимы.
19 записей, 16 различных ID. Периода настоящих наблюдений нет.
CSV: UTF-8, разделитель «;», числа первоначально читаются как строки.

| Поле | Смысл и договорённость источника |
|---|---|
| Request ID | Строковый идентификатор |
| Age | Возраст; правила этой учебной формы допускают целые 16…100, пустота допустима |
| Education | Свободный текст; «высш.» означает «высшее», «СПО» — отдельную категорию |
| Duration, Unit | Длительность: «час» означает астрономический час 60 минут; «мин» — минуты |
| Fee RUB | Стоимость одной заявки в рублях; пробелы могут разделять разряды |
| Format | Групповой или индивидуальный формат; суммы между форматами не обязаны быть сопоставимы |

Известные особенности искусственного источника:
- 004: нулевая стоимость соответствует промоместу; 240 в Age — ошибка, верное значение неизвестно.
- 003: отрицательная длительность — ошибка неизвестной причины. Нельзя считать модуль исправлением без подтверждения. «уточняется» — неизвестная стоимость.
- 008: поля Age/Duration/Fee RUB не заполнены. Причина не сообщена.
- 012: стоимость 300000 подтверждена условиями учебного источника как индивидуальный пакет; не опечатка. Это не значит, что её надо смешивать с групповыми занятиями.
- 001 повторён полностью; 002 повторён с другим написанием Education.
- 016 имеет конфликт стоимости 2100/2300. Порядок выгрузки не задаёт актуальную версию; требуется уточнение, обе записи сохраняются отдельно для разбора.

`requests_stage1.csv` — предоставленный промежуточный результат основного пути
05.1 для независимого старта 05.2. Он сохраняет все 19 записей, исходные числовые
строки и признаки неизвестности/ошибок; новых наблюдений в нём нет. Полностью
воспроизводится кодом 05.1 без выполнения «Ваш ход». Числа в новом файле с точкой,
разделитель — запятая, кодировка UTF-8. Это контрольная копия, не ответы на упражнения.
