# Titanic: учебный снимок

Файл перенесён без изменений из существующих материалов курса (archive/previous_years/titanic.csv). 891 строка, поля PassengerId…Embarked; это обучающая выборка известной задачи Titanic, не полный манифест корабля. Публичная копия для сверки: https://github.com/datasciencedojo/datasets/blob/master/titanic.csv ; описание задачи и условий: https://www.kaggle.com/competitions/titanic/data . Исходная лицензия локального файла отдельно не зафиксирована; не считать учебную доступность разрешением любого коммерческого использования. Имена исторических пассажиров не являются данными студентов. Не переиздавайте этот файл как собственный датасет.
