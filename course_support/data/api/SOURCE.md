# Учебные ответы JSON

Данные созданы для курса А. А. Дуркина. Все должности, предложения и суммы вымышлены, это не реальные вакансии и не снимок API. Общая структура «items + сведения о страницах» моделирует распространённый ответ; имена полей и нумерацию всегда проверяют по документации конкретного сервиса.

Единица наблюдения — одна вымышленная вакансия, ключ id. salary.from/to — границы предложения, currency — валюта, gross=True означает до налогов, False — после. null означает, что поле не указано; нижняя граница не равна фактической зарплате. В странице4записи, нумерация0/1, всего8. JSON используется как учебный текст; запросы к реальному серверу для него не делались.

Учебные материалы и данные можно использовать в заданиях курса с указанием происхождения. По ним нельзя делать выводы о рынке труда, актуальных зарплатах или работодателях.
